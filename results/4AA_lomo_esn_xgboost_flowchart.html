LOMO ESN–XGBoost Evaluation Flow

One fixed joint hyperparameter combination • repeated for every held-out material
336 aligned thermal time series
14 materials × 4 temperatures × 6 repetitions
Create one LOMO fold
hold out one complete material
Training set
312 trials from 13 materials
Test set
24 trials from 1 held-out material
Construct five time-varying ESN input channels for every trial
  1. Smoothed primary sensor response
  2. Smoothed secondary sensor response
  3. Primary − secondary response
  4. Primary rate of change, dPrimary/dt
  5. Secondary rate of change, dSecondary/dt
Fit the five-channel input scaler
using only the 312 training trials
Transform the
312 training time series
Apply the same fitted scaler to the
24 held-out time series
Repeat independently for reservoir seeds 42, 43 and 44

Seed 42

Create reservoir with fixed ESN HPs
Run 312 training sequences → summarize trajectories into 312 ESN-feature rows
Run 24 test sequences through the same reservoir → summarize into 24 ESN-feature rows
Train XGBoost 42 on the 312 training rows and targets
Predict the 24 held-out trials

Seed 43

Create reservoir with fixed ESN HPs
Run 312 training sequences → summarize trajectories into 312 ESN-feature rows
Run 24 test sequences through the same reservoir → summarize into 24 ESN-feature rows
Train XGBoost 43 on the 312 training rows and targets
Predict the 24 held-out trials

Seed 44

Create reservoir with fixed ESN HPs
Run 312 training sequences → summarize trajectories into 312 ESN-feature rows
Run 24 test sequences through the same reservoir → summarize into 24 ESN-feature rows
Train XGBoost 44 on the 312 training rows and targets
Predict the 24 held-out trials
Average the three seed-specific predictions
one averaged prediction for each of the 24 held-out trials
Store 24 out-of-fold predictions
Move to the next material and repeat
until all 14 materials have served as the test material
Pool all 336 out-of-fold predictions
calculate pooled NRMSE, R² and across-fold stability
Within every fold, held-out target values are never used for scaler fitting, ESN-feature training or XGBoost fitting.
